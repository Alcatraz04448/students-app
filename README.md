# Список студентов

Итоговая работа по курсу "Специализированные инструменты прикладного программирования".

Консольная программа на Java для работы со списком студентов. Студент описывается тремя полями:
ФИО, средний балл и номер зачётной книжки.

Выполнен базовый уровень и оба дополнительных (2 и 3).

## Запуск

Нужна Java 17 или новее.

- IntelliJ IDEA: открыть проект и запустить класс `org.example.Main`.
- Из командной строки, находясь в папке проекта:

```
javac -encoding UTF-8 -d out -sourcepath src/main/java src/main/java/org/example/Main.java
java -cp out org.example.Main
```

## Меню

| Пункт | Действие |
|---|---|
| 1 | добавить студента с клавиатуры |
| 2 | загрузить студентов из текстового файла |
| 3 | вывести список в виде таблицы |

## Входной файл

Обычный текстовый файл в UTF-8, одна строка - один студент, поля разделены точкой с запятой:

```
Иванов Иван Иванович;4.50;210001
Петрова Анна Сергеевна;5.00;210002
```

В папке `data` два примера: `students.txt` (корректные данные) и `students_with_errors.txt`
(почти все строки с ошибками, чтобы проверить валидацию).

Правила проверки:
- ФИО - только буквы, пробелы и дефис, не длиннее 60 символов;
- средний балл - число от 2 до 5, дробную часть можно писать через точку или запятую;
- номер зачётки - ровно 6 цифр и не должен повторяться.

Если строка не прошла проверку, она пропускается, а программа пишет номер строки и причину.
Если файла нет или он не в UTF-8, выводится сообщение об ошибке, программа продолжает работу.

## Как устроено

- `entity/Student` - класс студента.
- `util/Validator` - проверка данных, при ошибке бросает `InvalidDataException`.
- `file/StudentFileReader` - чтение файла (try-with-resources).
- `StudentManager` - хранение студентов и операции над списком.
- `report/StudentReport` - отчёт через Stream API: filter по баллу, sorted по убыванию балла,
  map в строку "Фамилия И. О.", а также средний балл (`average`) и лучший студент (`max`).
- `list/CustomLinkedList` - собственный двусвязный список (уровень 2).
- `sorting` - собственные сортировки (уровень 3).

### Уровень 2

`CustomLinkedList<E>` - аналог `LinkedList`. Элементы лежат во вложенном классе `Node`, который хранит значение
и ссылки на предыдущий и следующий узел. Реализованы `add`, `get`, `remove`, `size` и свой итератор.
Класс наследует `AbstractSequentialList`, поэтому его можно использовать как обычный `List`.
Все студенты в программе хранятся в нём, стандартные `ArrayList` и `LinkedList` не используются.

Добавление - пункты 1 и 2, получение - пункт 4 (`get`), удаление - пункт 5 (`remove`), вывод - пункт 3.

### Уровень 3

Интерфейс `SortAlgorithm<T>`, абстрактный класс `ArraySortAlgorithm<T>` и две реализации:
`SelectionSort` (выбором) и `QuickSort` (быстрая). В пункте 7 пользователь выбирает алгоритм,
поле (ФИО, балл или номер зачётки) и порядок (по возрастанию или по убыванию).
